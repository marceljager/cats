Sem dávejte originály fotek (např. velik.jpg) a v src/content.js u příslušné položky
nastavte photo: '/photos/velik.jpg'. Ideální poměr stran je 4:5 (na výšku).
Zmenšené verze pro web (AVIF, WebP, JPEG v několika šířkách) se vyrobí samy do public/photos
při npm run dev a npm run build (nebo ručně: npm run photos). Do public/photos nic nedávejte.
